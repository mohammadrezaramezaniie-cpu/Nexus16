# Namdaran Agent OS

CrewAI-backed, quality-first multi-agent operating system.

Core capability agents:
- PO — Intent & Execution Optimizer
- EX — Executive Orchestrator
- CTX — Context Intelligence
- BUILD — Autonomous Product Builder
- OPP — Opportunity Intelligence
- STR — Strategy Director
- FIN — Finance Intelligence
- LEGAL — Legal & Contract Intelligence
- RES — Deep Research
- DATA — Data Intelligence
- PRES — Presentation & Communication
- AUTO — Automation Engineer
- QC — Quality Gate / Red Team

Execution rule: simple requests bypass crews; complex/high-value requests are expanded by PO, planned by EX, executed by the minimum useful specialist crew, and must pass QC before finalization.

This repository is the deployment source for the CrewAI runtime. CrewAI account authorization and cloud deployment are still required before remote execution/MCP export becomes live.
